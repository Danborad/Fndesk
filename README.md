## ✨ 核心亮点

- **⚡ 飞牛原生应用图标 (Native App)**
  - 基于飞牛官方套件规范，一键生成独立的 APP 桌面图标与启动项。
  - 完全独立存在，支持在飞牛应用中心随时**一键干净卸载**，不污染系统，不残留冗余文件。
  - 跨端体验一致：Web 桌面、飞牛手机 APP、FN Connect 远程访问均可原生显示。

- **🎨 专业级图标工坊 (Icon Studio)**
  - **苹果 Squircle 平滑圆角**：内置仿 iOS/macOS 连续曲率超椭圆算法，告别生硬机械圆角。
  - **尺寸与内边距留白**：自由调节 Logo 缩放（20%~180%）与内边距（Padding），给标志留出优美的呼吸空间。
  - **丰富底色与渐变风格**：
    - 透明底色（PNG）
    - 品牌纯色（内置 Docker 蓝、Jellyfin 紫、Plex 橙、Portainer 青、fnOS 官方蓝等 16 款常用色板）
    - 高级渐变（双色线性渐变，角度自选，内置蓝紫幻境、落日晚霞、极光青绿等多套预设）
  - **立体柔和投影**：可选 Logo 柔和层次投影，让扁平白色标志在彩底上更加立体高级。
  - **桌面实景预览**：实时模拟在飞牛桌面壁纸与文字标签下的实际视觉呈现，所见即所得。

- **🐳 Docker 容器一键导入**
  - 自动嗅探 NAS 本机正在运行的 Docker 容器列表。
  - 一键带入容器名称、镜像信息与对外映射端口，无需手动记忆与输入。

- **🌐 高清 Favicon 自动嗅探**
  - 输入目标网址或端口后，后端自动抓取目标站点的 Web Favicon 或 Apple Touch Icon，无需手动到处找图。

- **🚀 极简纯净开源架构**
  - **零外部二进制黑盒**：彻底剔除原版 8MB 闭源的 `fndesk-go` 二进制程序。
  - **剥离无关冗余**：移除音乐播放器、ffmpeg 转码、Win98/XP 仿造主题、开机音效、硬件伪装等臃肿代码，仅占用十几兆系统内存。
  - **原生 Node.js 服务**：全开源 JavaScript 实现，透明、安全、可控。

## 🛠️ 安装与使用

### 1. 本地安装（开发与测试）
在飞牛 NAS 终端中进入项目目录，执行：
```bash
appcenter-cli install-local
```

### 2. 打包与应用中心安装
也可以通过生成 `.fpk` 安装包，在飞牛应用中心左下角选择**手动安装**。

### 3. Web 管理地址
安装启动后，访问：
```
http://<你的飞牛NAS内网IP>:9990/
```
或在飞牛桌面点击 **Fndesk Lite** 快捷方式进入管理面板。


## 🔒 密码与数据安全

- **数据存储路径**：所有图标配置全量存储在 `@appshare/fndesk/deskdata/data.json` 中，套件升级或重装均可安全保留。
- **管理密码**：首次进入可在界面设置管理密码（SHA-256 加密保存于 `pw.json`）；若忘记密码，删除 `deskdata/pw.json` 即可重新初始化。
